# 🌊 Frontsea Mark

> 留住温度、速度、温柔和愤怒。

一款纯净极简的图片水印生成工具，专为创作者设计，支持导入任意Google Fonts作为水印文字。您可以直接在网页端即开即用，也可以下载 macOS 桌面端享受更原生的体验（目前仅支持Mac端，后续会适配Win和Android）。

## 🌟 核心功能

- **🔒 绝对隐私安全**：完全纯前端实现，照片无需上传至任何服务器，一切处理均在您的浏览器 / 桌面应用本地瞬间完成，100% 保护隐私。
- **✨ 极简高级设计**：采用符合现代审美的浅色系冰白玻璃拟态（Glassmorphism）三栏式 UI，沉浸式的全屏中央画板配合极简排版控制。
- **🎮 创新摇杆交互**：自带物理阻尼回弹的丝滑“虚拟摇杆”，结合屏幕尺寸优化的灵敏度，方便对图片水印进行精确到像素级的盲操微调。
- **🔤 开放式字体排印**：内置多款精选字体组合（支持任意 Google Fonts 动态链接挂载），完整实现对字重（100-900）、斜体、不透明度的全方位高自由掌控。
- **💻 多端自适应与跨平台支持**：支持电脑端与手机端浏览器的顺畅断点缩放体验；本项目同时基于 Electron 进行了深度重组，提供了完整的 macOS (dmg) 安装包以及原生系统级的文件保存对话框。

## 📦 如何使用

### 方式一：直接使用 Mac 桌面完整版 (推荐)
前往项目页面的 **[Releases]** 标签页，下载最新的 `Frontsea Mark-x.x.x.dmg` 文件，双击打开后拖拽至「应用程序」即可享有原生级的完整水印使用和另存为体验。

### 方式二：网页端即开即用
直接用浏览器打开项目中的 `index.html` 文件，即可在任意操作系统与设备上使用全部网页版功能。

### 方式三：开发者自行构建
如果您处于开发环境，或者想要二次开发：
1. 请确保您的电脑安装了 Node.js 环境。
2. 终端进入本工程目录，安装依赖：
   ```bash
   npm install
   ```
3. 启动开发环境桌面测试版：
   ```bash
   npm start
   ```
4. 构建打包生成专属于您的独立 Mac `dmg` 安装文件：
   ```bash
   npm run dist
   ```

## 🛠 技术栈
- **UI & 渲染**：HTML5, CSS3, Vanilla JS (纯原生，无框架依赖)
- **图形处理**：Canvas 2D Rendering Context
- **桌面包装器**：Electron, electron-builder
